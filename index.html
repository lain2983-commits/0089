열전달 기본 이론 (NTU-ε법)
① NTU 계산 (Number of Transfer Units)
NTU = h · Atotal · α / (ρ · Q · Cp)
h : 대류 열전달계수 (W/m²·K) — Dittus-Boelter 상관식
Atotal : 전면 면적 = W × H (m²)
α : 비표면적 (채널당 열전달 면적 밀도, m²/m³) — Pitch↓ 시 증가
ρ : 공기밀도 1.2 kg/m³
Q : 풍량 (m³/s)
Cp : 공기 정압비열 1005 J/kg·K
② 열전달계수 h (Dittus-Boelter 식)
h = 0.023 · Re0.8 · Pr0.4 · λ / dh
Re : 레이놀즈수 = v · dh / ν (ν = 1.5×10⁻⁵ m²/s)
Pr : 프란틀수 = 0.71 (공기)
λ : 공기 열전도율 = 0.026 W/m·K
dh : 수력직경 = 기본값 4mm × (Pitch/1.5) — Pitch 비례 보정
③ NTU → 효율 변환 (대향류 열교환기 기준)
ε = NTU / (NTU + 1)
열용량비 C* = 1 (동일 풍량 대향류) 조건 적용
역산 시: NTU = ε / (1 − ε)
효율 보정 단계별 수식
④ 전체 계산 흐름
STEP 1 · 이론효율
εtheory = NTU(W,H,D,Q,Pitch) × Ccal → ε변환
Ccal: DB 가중 보정계수 (실측DB 없으면 1.000)
STEP 2 · 손실 반영
εloss = εtheory × Ltotal
Ltotal = ∏ Li (활성화된 손실인자만 곱산)
STEP 3 · 소재 보정
εmat = εloss × Smat
Smat: 소재별 열전달 보정계수 (Al=1.00, SUS=0.98 등)
STEP 4 · 마진 차감 (Safety Margin)
εfinal = εmat − M
M: 설계 여유값 (기본 1.5%) — 토글로 표시/숨김 가능
마진률 및 보정계수 상세
⑤ 설계 여유값 (Safety Margin) M
εfinal = εmat − M  (M 기본값: 1.5%)
KS B 6879 공인시험과 설계예측치 사이에는 제조 공차, 시험환경 편차 등으로 오차가 발생합니다. 마진은 이 오차를 흡수하는 보수적 설계 여유입니다.

마진값의미권장 용도
0 %마진 없음이론값 그대로
1.0 %최소 여유실측DB 충분 시
1.5 %표준 여유일반 설계 (기본)
3.0 %보수적 여유신규 개발품
5.0 %최대 여유초기 개념 설계
⑥ DB 가중 보정계수 Ccal
Ccal = Σ(wi · Ci) / Σwi
Ci = NTU역산(실측) / NTU계산(이론)
wi = 1 / disti  (거리 역수 가중)
실측 DB의 각 데이터 포인트에서 이론 NTU와 실측효율의 비율을 계산하고, 입력 조건과의 거리(치수·풍량·Pitch 차이)에 반비례하는 가중치로 평균합니다.

⚠ 실측 DB가 없으면 Ccal = 1.000 (순수 이론값 사용)
데이터가 많을수록, 현재 조건과 유사할수록 정확도가 향상됩니다.

⑧ 전열(ERV) 잠열 계산
εlatent = ε(NTU × CL × Le) × Lc
εtotal = (εsensible + εlatent) / 2
Le : Lewis수 보정 = 0.9 (열·물질 전달 비율)
CL : 잠열 DB 가중 보정계수 (현열과 별도 관리)
Lc : 소재 잠열 보정계수 (Al=0.00 투습불가, 크라프트지=1.00 등)
